画像埋め込みQRコード最適化

QR生成後のモジュール改変や誤り訂正への依存ではなく、QRエンコーダに入力する可変ペイロードだけを操作して、画像に似た正しいQR符号を探索するツールです。

Phase 1 実装済み

  • Byte Modeを明示したQR生成
  • Version / ECC / Maskの固定
  • 固定・可変ペイロードセグメント（複数対応）
  • 可変ASCII文字集合に完全包含される最大次元アフィン部分空間 A = b xor V の厳密探索
  • 基準QR M0 と、各自由変数を1つ変更してQRエンコーダを再実行した差分 Di の構築
  • QR構造上固定 / 現在の条件で固定 / 可変モジュールの分類
  • GF(2)ガウス消去による絶対黒・絶対白モジュール制約の求解
  • 一般解 x = xp xor N z の残存自由度からのみ候補を生成
  • ランダム点での M0 xor Σ xi Di と実エンコーダ行列のセルフテスト

Phase 2 実装済み

  • 元画像読み込み、二値化、しきい値、明るさ、コントラスト、反転
  • Crop / fit / zoom / 位置調整
  • 目標画像を四隅のQR構造から内側へ縮小する設定
  • 重要度マップ、絶対黒・絶対白ブラシ
  • 重要度順に両立する独立条件を追加するヒューリスティック
  • 残存零空間からの複数候補生成とスコア比較
  • 同一VersionでMask 0〜7を独立問題として比較
  • 各可変セグメントについて探索開始 / 探索終了 / 粗探索Step / 細探索±幅を指定
  • 粗探索Step 0 では、指定したAuto目標点数からStepを自動決定
  • 粗探索・細探索の全長さ候補では Di を作らず、代表QRだけで軽量スクリーニング
  • 軽量スコア上位の指定件数だけ、M0 / Di + GF(2) をフル求解
  • 複数可変セグメントでは各軸の探索値の直積を軽量比較
  • 各可変セグメントを、他の現在条件を保ったまま収容可能な最長長さへ設定するボタン

可変長探索の扱い

各可変部の現在の長さ欄は「探索終了 / 最大長」として扱い、別途「探索開始」「粗探索Step」「細探索±幅」を指定できます。

例えば探索範囲 1〜1000、粗探索Step 50 なら、まず約50刻みで長さ候補を軽量評価します。ここでは各候補について Di を構築せず、許可文字集合から決定的に作る少数の代表ペイロードをQR化し、目標画像との重み付き一致と「可変bit数上限 / 非構造モジュール数」から候補順位を付けます。

粗探索後の細探索も同様にまず軽量評価です。最終的に「最後にフル求解する上位長さ」で指定した件数だけ、従来どおり文字集合の厳密アフィン解析、Version/Mask確定、基準 M0、差分 Di、GF(2)求解、画像最適化を実行します。したがって、探索範囲を広げても重い Di 構築回数はこの上位件数で直接制御できます。

軽量代表QR数の既定値3、フル求解上位数の既定値5、粗探索Auto目標点数20、細探索上位3、細探索±幅20などはQR規格値ではなく、計算時間と探索粒度のトレードオフとして置いた暫定UI既定値です。すべてUIで変更できます。

軽量スコアは最終的なGF(2)最適化スコアの保証値ではありません。Di の実rankや絶対制約の可解性は軽量段階では評価せず、最終候補として表示するQRは必ずフル求解を通過したものだけにします。

all masks がONの場合も、軽量段階は現在のMask指定1通り（Mask AutoならQRエンコーダ標準Auto Mask）だけで長さを比較します。上位長さのフル求解に進んだ後は、既存仕様どおりMask 0〜7を独立問題として比較します。

QR VersionがAutoで長さによって行列サイズが変わる場合、目標画像・重要度は基準問題の正規化座標を基準に最近傍で対応付けます。これはQR規格上の処理ではなく、異なる行列サイズ間でユーザー指定領域を対応付けるための実装上の判断です。
