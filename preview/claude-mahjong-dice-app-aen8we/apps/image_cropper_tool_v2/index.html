🖼️ 画像トリミング＆座標取得ツール

使い方

  • このツールは、Poke-ControllerのisContainTemplate関数用の画像の切り抜きとcrop範囲指定を行います
  • 画像をドラッグ&ドロップするか、ファイルを選択してアップロード（複数ファイル選択対応）
  • 画像上をドラッグしてトリミング範囲を選択、またはテキストボックスで直接座標を入力
  • crop範囲座標を [l, t, r, b] 形式でコピー
  • 切り抜き画像をダウンロードボタンで取得
  • 複数ファイルの場合、一覧から切り替えて同じ範囲で一括処理可能

座標の意味

  • l (left): 左端のx座標 - 横軸 l = x
  • t (top): 上端のy座標 - 縦軸 t = y
  • r (right): 右端のx座標 - 横軸 r = x + w
  • b (bottom): 下端のy座標 - 縦軸 b = y + h
