## 概要

「リンク先URL（絶対に必要な文字列）」と「自由に変えていい部分の制約」を指定すると、
その制約内で **元画像に一番近い模様になる文字列** を総当たりで探し、候補を並べるツール。

- **線形解法（既定）**: QRの「ペイロードのビット → モジュール」は GF(2) 上のアフィン写像
  （`M(x) = M0 XOR Σ xi・Di`）なので、目標パターンから文字列を逆算できる。
  輪郭に近く重みの大きいモジュールから順に方程式を立ててガウス消去で解く。
  基底はマスクに依存しないため、8マスク分の右辺を1回の消去でまとめて処理する
- **ランダム探索**: 文字種・長さを自分で指定したいとき用。一致率は50%＋数ポイントが上限
- 自由部分は `H-W / h-w` の32文字（`0x48 XOR {1,2,4,0x18,0x20}` というビット部分空間になっている英字）を使い、
  1文字あたり5ビットの自由度を確保する（英字だけで作れる部分空間としてはこれが最大）
- 描画は「画像と一致しているモジュールのドットを薄くする」ハーフトーン方式で、写真を透けさせつつ読み取りやすさを保つ
- 出力ごとに jsQR で自動デコードして「読取OK / 読み取れず」を判定
- **描画は行列を壊さない構成**: 黒モジュールは 0〜70、白モジュールは 186〜255 の明度しか使わず、
  その帯の中で写真の明暗を再現する。セルのどこをサンプルされても読み違えないので、
  誤り訂正の余力は構成上ゼロ消費（後から修復する処理は不要）。
  絵は「モジュールの並び」＋「画像と一致するモジュールはベタ塗り／食い違うモジュールは小さいドット」で作る
- わざと壊すのはロゴ穴と「強調範囲のはみ出しを消す」だけ。描く前にRSブロックごとの訂正能力の25%までに絞り込む
- 出力画像を1モジュールずつ2値化して正しい行列と比較し、符号語→RSブロックに割り当てて
  **誤り訂正の余力使用率**を実測表示する（jsQRの合否だけでは「ぎりぎり読めている」状態が分からないため）。
  ファインダーの角丸やロゴ穴が機能パターンを壊している場合も警告する

検証済みの事実:

- モジュール行列は node-qrcode の出力そのままで、1ビットも書き換えていない。
  独立実装（Python `qrcode`）と5構成でビット単位一致を確認
- ファインダーの角丸は強さ0.8までならOpenCVのデコーダも通るが、1.0（旧実装の固定値）だと
  1:1:3:1:1 の比率が崩れて検出に失敗する。既定は0.35
- 余力使用率92%の出力は jsQR では「読取OK」でも OpenCV では読めない。アプリ内の実測値は
  Python 側の独立検算と完全一致（0% / 31% / 31% / 92%）
- 修復をドット状に塗ると角に下地が残り、スキャナのサンプリング位置が少しズレただけで読み違える。
  セル全体を塗ることで解消（写真の下地あり・ドット0.86・ECC L で OpenCV が落ちていたのが通るようになった）
- 描画を作り直した後: ECC L/M/Q/H × 写真の強さ0.85/1.0 のすべてで誤りモジュール0・余力使用0%・OpenCVデコード成功。
  ロゴ穴とはみ出し消しを併用しても上限どおり23%に収まり、デコードも成功
- 丸ドットは OpenCV の**検出**（デコード以前）を失敗させることがあるため既定は四角ドット

モチーフの指定（塗りツール）:

- 目標パターンの上をドラッグして「絶対白 / 絶対黒 / 重要度」を指定できる。
  重要度は連続値（0=どうでもいい〜1=最重要）で、重みを 1/6〜6 倍する。
  背景の重要度を下げると自由ビットがモチーフ中心に回る（実測: 一致率 57.0% → 60.6%、中心の再現が明確に向上）
- 「動かせないモジュールを表示」で、固定URL（必須文字列）と符号構造のせいで白黒を変えられない
  モジュールを可視化する（赤＝どんな文字列でも不可、橙＝32文字アルファベットの制約で不可）。
  ペイロード各バイトの bit0〜6 を1本ずつ反転した差分を集めて判定する（実測: 型番7・ECC H・
  プレフィックス29文字で、データ領域1568のうち699が変更不可、35が文字集合由来、834が可動）
- 塗りは版に依存しないよう正規化グリッド（160×160）に保持し、モジュール座標へサンプルする
- 線形解法では塗った範囲の方程式を最優先で解き、描画側でも下地をベタ塗りして写真を消す
- QRの符号構造上、動かせないモジュールが全体の約半分ある（固定URL部分のバイト／アルファベットで
  固定される3ビット／自由バイトを含まないRSブロックのEC語）。実行後に達成率と「動かせなかった数」を表示
- 残ったはみ出しは「強調範囲のはみ出しを薄く」で誤り訂正の余力を使って消せる

実測（合成写真・型番6・ECC L）: ランダム探索 53% に対し線形解法は **71.8%**、所要時間は 0.2 秒。
- 画像はすべてブラウザ内で処理され、外部に送信されない

## サーバーなしで任意のページに飛ばす仕組み

多くのサイトは知らないクエリパラメータを無視するので、
`https://example.com/page?qr=xxxxxx` の `xxxxxx` を自由部分にすれば、
リダイレクタを持たなくても「リンク先は任意・見た目は自由」を両立できる。
自前のリダイレクタがある場合はテンプレートモードで `https://example.com/r/{}` のように書ける。
