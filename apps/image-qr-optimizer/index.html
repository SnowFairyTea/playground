画像埋め込みQRコード最適化

QRを壊して画像に似せるのではなく、QRエンコーダへ与えるペイロード自由度から、目的のモジュール配置を数学的に作るためのツールです。

Phase 1 — QR自由度の解析

現在の実装範囲は Byte Mode固定、可変文字集合のアフィン部分空間化、M0 / 差分基底 Di、固定・可変モジュール判定、GF(2)連立方程式による指定モジュール制約の求解です。画像最適化と独立デコーダ/RS検証はまだ実装していません。

1. ペイロード構成

固定・可変セグメントを任意の順序で複数配置できます。固定部はUTF-8、可変部はPhase 1では1文字=1バイトのASCII文字集合に限定します。

2. QR構造条件

AutoはPhase 1では「基準ペイロードを収容できる最小Versionを決め、その後固定」です。
既定Mは実装上の暫定既定値で、規格が推奨する固定値ではありません。
Phase 1のAutoは画像一致では選びません。0〜7を個別指定できます。
Phase 1アルゴリズム上の制約。将来モード追加可能。
暫定値8。最大次元の証明には影響せず、同次元候補を何件表示するかだけを制限します。
暫定値8。ランダムな解ベクトルで実エンコーダと M0⊕ΣxiDi を照合する実装確認用です。

4. 固定QR問題を構築

選択したVersion / ECC / Mask / Byte Mode / ペイロード長 / 可変バイト位置を固定し、基準QR M0と各自由変数を1つだけ反転した実エンコーダ出力との差分から Di を構築します。

文字集合の解析後に実行できます。

5. 固定 / 可変モジュール可視化と絶対制約

セルをクリックすると「制約なし → 絶対黒 → 絶対白 → 制約なし」と切り替わります。これは画像処理ではなく、Phase 1のGF(2)求解確認用です。
