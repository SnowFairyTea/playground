# 画像埋め込みQRコード最適化

QR生成後のモジュール改変や誤り訂正への依存ではなく、QRエンコーダに入力する可変ペイロードだけを操作して、画像に似た正しいQR符号を探索するツールです。

## Phase 1 実装済み

- Byte Modeを明示したQR生成
- Version / ECC / Maskの固定
- 固定・可変ペイロードセグメント（複数対応）
- 可変ASCII文字集合に完全包含される最大次元アフィン部分空間 `A = b xor V` の厳密探索
- 基準QR `M0` と、各自由変数を1つ変更してQRエンコーダを再実行した差分 `Di` の構築
- QR構造上固定 / 現在の条件で固定 / 可変モジュールの分類
- GF(2)ガウス消去による絶対黒・絶対白モジュール制約の求解
- 一般解 `x = xp xor N z` の残存自由度からのみ候補を生成
- ランダム点での `M0 xor Σ xi Di` と実エンコーダ行列のセルフテスト

## Phase 2 実装済み

- 元画像読み込み、二値化、しきい値、明るさ、コントラスト、反転
- Crop / fit / zoom / 位置調整
- 目標画像を四隅のQR構造から内側へ縮小する設定
- 重要度マップ、絶対黒・絶対白ブラシ
- 重要度順に両立する独立条件を追加するヒューリスティック
- 残存零空間からの複数候補生成とスコア比較
- 同一VersionでMask 0〜7を独立問題として比較
- 各可変セグメントについて探索開始 / 探索終了 / 粗探索Step / 細探索±幅を指定
- 粗探索Step `0` では、指定したAuto目標点数からStepを自動決定
- 粗探索の上位長さ組合せだけを、指定した細探索Stepで局所再探索
- 複数可変セグメントでは各軸の探索値の直積を独立QR問題として比較
- 長さごとに文字集合解析、M0 / Di構築、画像最適化をやり直し、総合候補を重要度付き一致スコアで比較
- 各可変セグメントを、他の現在条件を保ったまま収容可能な最長長さへ設定するボタン

### 可変長探索の扱い

各可変部の現在の長さ欄は「探索終了 / 最大長」として扱い、別途「探索開始」「粗探索Step」「細探索±幅」を指定できます。

例えば探索範囲 `1〜1000`、粗探索Step `50` なら、まず約50刻みで粗く評価します。粗探索後の「細探索する上位組合せ数」が3、「細探索±幅」が20、「細探索Step」が1なら、粗探索の上位3組合せの周辺だけを1刻みで再評価します。

粗探索Stepを `0` にするとAutoです。「粗探索のAuto目標点数 / 軸」の既定値20を使い、探索範囲を概ね20点で見るようにStepを決めます。この20、細探索上位3、細探索±幅20はQR規格値ではなく、計算時間と探索粒度のトレードオフとして設定した暫定UI既定値です。すべてUIで変更できます。

異なるペイロード長を同じ線形写像へ混ぜません。各長さ（複数可変部では各長さ組合せ）ごとに、文字集合解析、Version/Mask確定、基準 `M0`、差分 `Di`、GF(2)求解を独立して実施します。

UIには粗探索件数と細探索の最大見込み件数を事前表示し、中断ボタンも用意します。探索中に評価済みの長さ組合せは重複実行しません。

QR VersionがAutoで長さによって行列サイズが変わる場合、重要度・絶対制約は基準問題の正規化座標を基準に最近傍で移送します。これはQR規格上の処理ではなく、異なる行列サイズ間でユーザー指定領域を対応付けるための実装上の判断です。
