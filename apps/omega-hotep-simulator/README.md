# オメガホテプシミュレーター

オメガホテプの「ファンファーレ」を、1クリックで連鎖実行できるミニシミュレーターです。  
ブラウザだけで動作し、勝敗・チェイン数・効果内訳をその場で確認できます。

## できること

- ファンファーレ連鎖の自動実行
- 4種効果（フォロワー破壊 / リーダー2ダメージ / PP+2 / +4/+4）をランダム2択で適用
- 勝利・連鎖停止・上限到達の結果表示
- 効果発動回数のサマリー表示
- 結果の共有（URLコピー / X投稿）
- `seed` 付きURLでリプレイ再現
- シークレットの強制チェイン切替
- 20チェイン上限 / 実質無制限モード切替
- 超進化ボタンで追撃チェイン

## 使い方

1. `ファンファーレ発動` を押す
2. ログと盤面変化を確認する
3. 結果表示後、必要に応じて `URLをコピー` または `X投稿`
4. 再試行は `リセット`

## 共有URL仕様

ハッシュ付きURLで同じ挙動を再現できます。

- `#seed=<number>`: 乱数シード指定
- `&force=1`: 強制チェインON
- `&nolimit=1`: 無制限モードON

例:

```text
/apps/omega-hotep-simulator/#seed=123456789&force=1&nolimit=1
```


## 注意

このツールはファンメイドの挙動シミュレーターです。  
厳密なゲームロジック検証ではなく、挙動イメージを楽しく試す用途を想定しています。
