# image_cropper_tool

画像をアップロードして矩形範囲を指定すると、その矩形の四隅座標を取得できる


## 旧版との差分 (v2)

- 複数ファイルの一括読み込みとサムネイル一覧に対応
- 1つの範囲指定を全ファイルへ適用できる
- 座標の数値入力パネルを追加し、手入力で微調整できる
- 変更と同時に自動でトリミング結果を更新する
- トリミング結果のギャラリー表示と個別ダウンロードに対応
- 全トリミング結果のまとめダウンロード（ZIP）に対応
