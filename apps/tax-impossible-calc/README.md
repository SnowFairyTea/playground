# 税込で絶対存在しない金額計算機

消費税(10%・8%・任意税率)を掛けて端数処理(切り捨て/四捨五入/切り上げ)すると、
どんな税抜価格からも到達できない「絶対に存在しない税込金額」が発生します。

- 金額を入力すると、その金額が税込価格として存在できるかを判定
- 存在する場合は元の税抜価格を表示、存在しない場合は「飛ばされる瞬間」を表示
- 端数処理3方式 × 税率の比較表
- 指定範囲内の「存在しない金額」一覧の生成
