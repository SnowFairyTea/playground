PPAP（**P**asswordつきzipファイルを送ります・**P**asswordを送ります・**A**んごうか・**P**rotocol）を皮肉る単語からパスワードを生成するネタ半分・実用半分のツール。

## 機能

- **皮肉り用単語リスト**: PPAP風刺単語がデフォルト。1行1単語で自由に編集可能
- **文字数の下限・上限**: 範囲外なら自動でパディング/再生成
- **必須文字種の選択**: 大文字・小文字・数字・記号。欠けていればランダム位置に挿入して補完
- **辞書耐性ランダム化レベル**（4段階）:
  - `PPAP級` — 単語をつなぐだけ
  - `気休め級` — 単語ごとのケースランダム化
  - `Leet級` — a→@ / e→3 等の置換をランダム適用
  - `原型崩壊級` — さらにランダム文字を挿入
- **区切り文字**: なし / `-` / `_` / `.` / ランダム記号
- **エントロピー概算と皮肉入り強度判定**: 消費した乱数量から bit 数を積算し、総当たり解読時間の目安と辛口コメントを表示

乱数は `crypto.getRandomValues` を使用。生成はすべてブラウザ内で完結する。
