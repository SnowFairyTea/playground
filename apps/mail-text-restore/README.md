# メール復元ツール

テキストとして貼り付けられた／保存されたメールを、読める形に復元するブラウザツール。
処理はすべてブラウザ内で完結し、入力内容はどこにも送信されない。

## 対応している崩れかた

| 処理 | 例 |
|------|-----|
| エスケープ復号 | `\n` `\t` `あ` `\x41` |
| メールソース解析 | `.eml` のヘッダー + MIME パート（multipart / 添付あり）から本文を抽出 |
| MIMEヘッダー復号 | `=?UTF-8?B?...?=` / `=?ISO-2022-JP?Q?...?=` |
| quoted-printable 復号 | `=E3=81=82`、行末の `=`（ソフト改行） |
| Base64 復号 | 本文全体が Base64 の場合 |
| HTMLをテキスト化 | `<br>` `<p>` `<li>` を改行・箇条書きへ、タグを除去 |
| HTMLエンティティ復号 | `&gt;` `&nbsp;` `&#12354;` |
| パーセントエンコード復号 | `%E3%81%82` |
| 引用記号を除去 | 行頭の `>` `＞` |
| 折り返しを結合 | 72桁などで強制改行された行を段落へ戻す |
| 空白・空行の整形 | 行末空白 / NBSP / ゼロ幅文字 / 3行以上の空行 |

文字コードは `Content-Type` の `charset` を見て `TextDecoder` で復号する。
UTF-8 / Shift_JIS(CP932) / ISO-2022-JP / EUC-JP / ISO-8859-1 などに対応。
charset が無い・判別に失敗した場合は候補を順に試して、テキストとして妥当なものを採用する。

## 使い方

1. 崩れたメールを貼り付ける（`.eml` / `.txt` ファイルを開くことも可能）
2. 自動判定で必要な処理が適用され、実際に効果があった処理が緑色で表示される
3. うまく戻らないときは「自動判定にまかせる」をオフにして処理を手動で選ぶ
4. 結果をコピー、または `.txt` として保存

メールソースを読み込んだ場合は、件名・差出人・宛先・日時・添付ファイル名を復号して一覧表示する。
「結果にも含める」をオンにすると、復元結果の先頭にヘッダーを付けて出力できる。

## 制限

- `.msg`（Outlook 独自形式）のバイナリには非対応（テキスト化済みのものは可）
- 折り返しの結合は行幅の統計にもとづくヒューリスティック。過剰／不足する場合は手動でオン・オフする
