## 概要

ブラウザで振れるサイコロアプリ。

### 麻雀モード

6面ダイス2個を振り、以下を自動で判定・表示します。

- **誰の山か** — 出目の合計を自分から反時計回りに数えた席（自分 / 下家 / 対面 / 上家）
- **山を割る位置** — その人の山の右端から出目の数だけ数えた幢の左側。17幢の図で赤線と色分けで表示

親決めにも配牌の開始位置決めにもそのまま使えます。

### フリーモード

個数（1〜6個）と面数（D4 / D6 / D8 / D10 / D12 / D20 / D100）を選んで振れます。
D6 以外は数字表示になります。

## 実装メモ

- 乱数は `crypto.getRandomValues` を使用し、剰余バイアスを除去した一様分布
- サイコロの目は CSS グリッド（3×3）でピップを配置。1 の目は日本式に赤く大きく表示
- スペースキー、またはサイコロ本体のタップでも振れる
- 直近12件の履歴を保持
