一見ランダムなパスワードの中に、指定した任意の文字列を紛れ込ませて生成するツール。覚えておきたい合言葉やマーカーを埋め込みつつ、残りを暗号論的乱数で埋めるので、見た目はただのランダム文字列になる。

## 機能

- **仕込む文字列**: 必ず含めたい任意の文字（Unicode対応）
- **全体の文字数**: 仕込み文字を含む最終的な長さ
- **配置モード**（3種）:
  - `バラバラに散らす` — 仕込み文字の順序も崩して全体をシャッフル
  - `順序は保つ・位置はランダム` — 仕込み文字の並び順は維持したまま、位置だけランダム
  - `かたまりのまま・位置だけランダム` — 仕込み文字を連続ブロックのまま、開始位置だけランダム
- **フィラーの文字種**: 大文字・小文字・数字・記号
- **カモフラージュ**: 仕込み文字と同じ文字種にフィラーを寄せ、仕込み文字が浮かないようにする
- **種明かし表示**: 仕込んだ文字がどこに入ったかをハイライト表示（トグル）
- **エントロピー概算**: 配置＋フィラーで消費した乱数量を bit で表示

乱数は `crypto.getRandomValues` を使用。生成はすべてブラウザ内で完結する。仕込み文字列は既知情報のため、強度はフィラー部分の乱数量で決まる点に注意。
